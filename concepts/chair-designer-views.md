# 의자 002 — 디자이너들의 시각으로 본 '의자가 갖출 요소' (2026-10-08)

혼자 하는 일 4가지 → 필요한 자세: 바로 앉기(창작·처리·필기) / 앞으로 기울기(집중·필기) / 뒤로 기대기(관조·읽기) / 그 사이 오가기
'이 디자이너라면'은 기록된 설계 의도를 바탕으로 한 Claude 해석

| 디자이너 (의자) | 핵심 믿음 | 바로·앞으로 | 기대기 | 오가기 | 나오는 요소 |
|---|---|---|---|---|---|
| 옵스비크 (발란스, 카피스코) | 움직임의 자유는 받침만큼 중요. 정답 자세는 없다 | 안장·앞으로 기운 좌판 | 작은 등받이 (뒤·옆·거꾸로) | 막는 것이 없다 (팔걸이 없음) | 안장 좌판, 작은 등받이, 넓은 높이 범위 |
| 멩스훌·만달 (발란스) | 골반이 뒤로 말리는 게 문제 | 앞으로 기운 좌판 + 정강이 받침 | 약함 | 흔들리는 다리 | 기운 좌판, 정강이 받침 |
| 스텀프 (에르곤→에콰→에어론→엠바디) | 연구로 몸에 맞춘다 → 가만히 못 앉는 사람 → 덥지 않게 → 몸에 이롭게 | 조절되는 좌판 | 기울어지는 등받이 | 휘는 셸(에콰) | 크기·조절, 기울기, 그물망, 압력 분산 |
| 암바스·피레티 (베르테브라) | 의자가 몸에 저절로 반응해 몸의 연장처럼 사라진다 | 앞으로 따라 기움 | 뒤로 따라 기움 | 손 조작 없음 | 자동 기울기 기구 |
| 빌칸 (FS 라인, ON) | 움직이며 앉기 | 함께 휘는 셸 | 함께 휘는 셸 | 좌판이 3차원으로 | 유연한 셸, 움직이는 좌판 |
| 스틸케이스 (립, 제스처) | 척추는 사람마다 다르게 움직이고, 기기가 자세를 바꾼다 | 위·아래 등 따로 받침 | 기대면 좌판이 앞으로 | 좌판·등이 하나로 | 휘는 등받이, 미끄러지는 좌판, 넓게 움직이는 팔걸이 |

## 요소별 정리
| 요소 | 선택지 (누구의 시각) | 맡는 자세 |
|---|---|---|
| 좌판 형태 | 평평+조절(스텀프) / 앞으로 기움(만달) / 안장(옵스비크) | 바로·앞으로 |
| 등받이 | 작다(옵스비크) / 기울어진다(스텀프) / 척추 따라 휜다(스틸케이스) / 셸과 하나(빌칸) | 기대기 |
| 움직임 | 없음, 사람이 움직임(옵스비크 카피스코) / 자동으로 따라옴(암바스) / 셸이 휨(빌칸·에콰) | 오가기 |
| 조작 | 사람이 조절(에르곤) / 저절로(베르테브라·FS) | — |
| 표면 | 폼(에르곤) / 그물망(에어론) / 잘게 나뉜 면(엠바디) / 셸 | 압력·열 |
| 팔걸이 | 없음(옵스비크) / 넓게 움직임(제스처) | 오가기·기기 |
| 받침 | 바퀴+회전(대부분) / 흔들리는 곡면(발란스) | 이동·움직임 |

## 메모
- 우리 이상 '의자를 잊고 일에 몰입' ≈ 암바스 '몸의 연장처럼 사라지는 의자'
