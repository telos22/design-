# 의자 002 — 왼쪽 트리 (요구): 이상 → 방해 요인 → 역사 속 해결 방식

_2026-10-08 · 방법: `notes/reverse-conversion.md` · 자료: `notes/work-chairs.md`, `notes/chair-research.md`_

## 이상 (한 줄, 초안)
- 추상: **일하는 사람이 의자를 잊고 일에 몰입하게 하는 자리**
- 거꾸로 변환: 의자 때문에 일이 끊기는 순간(현실) − 방해 요인 D1~D14(현실) = 이상적인 의자
- 현실적 정의: **의자 때문에 일이 끊기는 순간이 0에 가까운 상태**

## 방해 요인별 역사 속 해결 방식
(근거: 연구 / 회사 연구 / 제조사 주장 / 일화 / 추정 / 조사 안 됨)

D1 일어나야 한다
- 다윈: 팔걸이 의자에 바퀴 (일화)
- 센트리피털(1849): 회전 좌판 + 바퀴
- 라킨(1904): 책상에 붙은 회전 의자 → 돌아서 다른 일 (형태에서 추정)

D2 몸에 안 맞아 고쳐 앉는다
- 에르곤(1976): 의학 연구로 정한 조절 (좌판·등받이)
- 에어론(1994): 몸 크기별 3사이즈 + 몸 따라 늘어나는 그물망
- 카피스코(1984): 넓은 높이 범위 (가스 실린더 150/200/265mm 선택)
- 근거: 몸 치수 5~95백분위 차이 (연구)

D3 한 자세로 굳는다
- 발란스(1979): 흔들리는 곡면 다리, 무릎 꿇기는 여러 자세 중 하나
- 카피스코: 앞으로·뒤로·옆으로·거꾸로 앉기
- FS 라인(1980): 함께 휘는 한 장 셸, 움직이며 앉기
- 립(1999): 기대면 좌판이 앞으로 미끄러져 여러 자세 유도 (제조사 주장)
- ON: 좌판이 3차원으로 움직임 (제조사 주장)
- 근거: 한 자세로 오래 = 통증과 관련 (연구) / 움직이는 의자만으로 효과는 증거 없음 (연구)

D4 골반이 뒤로 말린다
- 발란스: 앞으로 기운 좌판 + 정강이 받침 → 엉덩이 각도 열림 (Mandal 연구, 효과 연구는 엇갈림)
- 카피스코: 말안장 → 허벅지가 아래로 기울어 엉덩이 각도 열림 (제조사 주장)
- 립: 허리(아래 등)와 가슴(위 등)을 따로 받침 (회사 연구)

D5 기대거나 돌 때 의자가 안 따라온다
- 센트리피털: 숨긴 스프링 4개로 기울기
- 베르테브라(1976): 스프링·기구로 저절로 기울고 따라옴
- FS 라인: 자동 싱크로 + 휘는 셸
- 에콰(1984): 휘는 한 장 셸
- 립: 척추를 따라 휘는 등받이(LiveBack)
- 제스처(2013): 좌판과 등이 하나로 움직임
- ON: 좌판이 옆으로도 움직임

D6 자세를 바꿀 때마다 손으로 조절
- 베르테브라: 첫 자동 조절 사무 의자 (Met)
- FS 라인: 자동 싱크로 조절
- (반대 방식) 에르곤: 사람이 직접 조절

D7 덥고 땀이 찬다
- 에어론: 폼·천 대신 바람 통하는 그물망 (제조사 주장)

D8 한 곳이 눌려 저리다
- 에어론: 몸 따라 늘어나는 그물망, 구역별 장력 (판매처 자료)
- 엠바디: 잘게 나뉜 등받이가 미세한 움직임에 반응 (제조사 주장)
- ON: 압력이 고르게 나뉨 (제조사 주장)

D9 사람마다 척추 움직임이 달라 등받이가 안 맞는다
- 립: 4년·700명 연구 → 위·아래 등을 따로 받치는 LiveBack (회사 연구)
- 엠바디: 픽셀 등받이 (제조사 주장)

D10 휴대폰·노트북 볼 때 자세가 무너진다
- 제스처: 11개국 2000명 관찰 → 새 자세 9가지, 넓게 움직이는 팔걸이 (회사 연구)

D11 앉았다 섰다 할 때 높이가 안 맞는다
- 카피스코: 높은 실린더(최대 약 81cm), 발 받침 옵션 (판매처 자료)

D12 앉고 일어나기, 의자 빼고 넣기가 번거롭다 (추정)
- 센트리피털: 바퀴 / 라킨: 회전 (형태)
- 높은 좌판이 일어나기 쉽다는 설명은 조사 안 됨

D13 의자가 책상 아래에 부딪힌다 (추정)
- 라킨: 의자를 책상에 붙여 위치를 정함 (형태)
- 카피스코: 팔걸이 없는 모델이 대표적 (판매처 자료)
- 책상 001: 상판 밑 69.5cm, 프레임 4cm, 상자 바닥 57.5cm → 팔걸이 높이 확인 필요

D14 소리·흔들림이 집중을 깬다 (추정)
- 조사 안 됨

## 이상적인 사람의 앉은 모습 (2026-10-08, 논의 중)
사용자: 제품보다 먼저 '이상적으로 앉아 있는 사람의 모습'을 정의해야 한다.
- 연구: 정답 자세 하나는 없음. 구부정과 통증의 관련은 약함 (O'Sullivan 2011, 청소년 1596명: 약한 관련, 심리·행동 요인이 더 강함). 구부정은 디스크 부담이 큼 (Bashir 2006 MRI, 약한 근거)
- 거꾸로 변환: 이상적인 앉은 모습 = 구부정하게 가라앉은 모습(현실) − 구부정을 만드는 원인(현실)
- 구부정의 원인 후보: 좌판이 높아 발이 안 닿음 / 좌판이 깊어 엉덩이가 미끄러짐 / 등받이가 너무 꼿꼿해 엉덩이 각도가 막힘 / 엉덩이 굽힘이 제한된 몸 / 근육 피로(20분 후) / 화면이 낮거나 멂(의자 밖)
- 이상적인 앉은 모습(조건 초안): ① 골반이 뒤로 눕지 않아 허리 곡선이 산다 ② 엉덩이 각도가 90°보다 열려 있다 ③ 발이 바닥에, 허벅지가 고르게 얹힌다 ④ 머리가 몸통 위 ⑤ 이 안에서 자세가 계속 바뀐다
- 전략: A 구조로 못 구부리게 막기 vs B 구부정의 원인을 빼서 바른 쪽이 가장 편하게 (Claude 추천 B)
- 출처: https://www.painscience.com/biblio/slouching-only-slightly-associated-with-adolescent-back-pain.html · https://espace.curtin.edu.au/handle/20.500.11937/30467 · https://pmc.ncbi.nlm.nih.gov/articles/PMC4483391 · https://pmc.ncbi.nlm.nih.gov/articles/PMC4155214 · https://www.sunrisemedical.com/education-in-motion/resources/seating/pelvic-and-spinal-postures · https://www.vivid.care/insights/advice-tips/posterior-tilt-specialist-seating/

### 사용자 정리: 이상적인 앉은 모습도 '하지 않아야 할 것'으로 나온다 (2026-10-08)
이상적인 앉은 모습 = 아래를 하지 않는 모든 자세 (기준값은 임시)
- N1 골반이 뒤로 눕지 않는다 (허리 곡선이 무너지지 않는다)
- N2 엉덩이 각도가 90°보다 닫히지 않는다
- N3 발이 뜨지 않고, 허벅지 한 곳이 눌리지 않는다
- N4 머리가 몸통보다 앞으로 나가지 않는다
- N5 한 자세에 오래(약 20분: 매트 연구에서 구부정해진 시점) 머물지 않는다
- N6 너무 오래(약 30분: 혈당·혈압 단기 실험) 일어나지 않고 앉아 있지 않는다
