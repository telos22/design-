# 의자 002 — 작업 노트

_상태: 1단계 이데아와 기능 정의 중 · 2026-10-08 시작_
_짝: 책상 001 (160×60, 높이 72cm 고정) · 철학: [No more, No less](../notes/no-more-no-less.md)_

## 왜 의자인가
- 책상과 짝 → 회사의 '한 사람 자리' 완성
- No less 원칙(편함, 몸 치수, 오래감)을 시험하기 가장 좋은 제품: 몸이 직접 닿는다

## 이상적인 의자의 정의 (논의 중)
- 사용자: 책상에 앉아서 일하기에 최적화된 것. 오래 앉아 있을 수 있어야 한다.
- 조사(`notes/chair-research.md`): 통증과 가장 관련 있는 건 '오래, 한 자세로' 앉는 것
  → '오래 앉아 있을 수 있다'를 '오래 앉아도 몸이 굳지 않는다'로 볼지 확인 중
- 받치는 의자(Aeron, Gesture) vs 움직이게 하는 의자(Variable Balans, Capisco, ON)

## 이데아 (후보, 사용자 확인 전)
- 책상: "한 사람이 앉아서 생각을 펼칠 수 있는, 비어 있는 면"
- 의자 후보: "생각하는 동안 몸을 잊게 해 주는 자리" (Claude 제안)

## 기능 후보 (Claude 제안, 사용자 경험으로 확정 예정)
| # | 기능 | 메모 |
|---|---|---|
| F1 | 앉은 몸을 받친다 (엉덩이·허벅지) | |
| F2 | 등을 받친다 | 기대는 자세를 쓰는지 확인 |
| F3 | 책상 72cm에 맞는 높이 | 사람마다 다름 → 조절? (원칙: 자유로 둔다) |

| F5 | 앉고 일어나기, 책상 앞으로 당기고 빼기 | 바퀴? |

## 기본 조건 (이데아에 쓰지 않음)
- 넘어지지 않는다, 무게를 버틴다

## 사용자에게 물어볼 것
- 지금 의자의 불편한 점, 오래 앉으면 아픈 곳
- 주로 하는 자세 (바로 앉기, 기대기, 다리 올리기, 양반다리)
- 하루에 몇 시간 앉는지
- 팔걸이, 바퀴, 회전을 쓰는지

## 로직 트리: 이상적인 의자 (2026-10-08, 정리 중)
목표: 책상에서 일하는 동안, 오래 앉아도 몸이 굳지 않게 받쳐 주는 도구 (정의 후보)
- E1 몸을 받친다: 엉덩이·허벅지(임스 셸, 에어론 그물망, 에르곤 폼) / 골반·허리(기운 좌판·열린 엉덩이 각: 발란스·카피스코, 허리 받침: 에르곤) / 기댈 때 등(에어론, 제스처)
- E2 몸이 굳지 않는다: 의자가 움직임(발란스 흔들림, FS 유연한 셸, ON) / 사람이 움직이기 쉽게(카피스코 여러 자세, 팔걸이 없음) / 일어나기 쉽게
- E3 몸과 책상에 맞는다: 높이 조절, 넓은 높이 범위(카피스코), 책상 72cm 기준
- E4 쓰는 방법이 단순하고 직관적이다 (확정 원칙)
- E5 오래간다: 튼튼한 재료·공정(네이비 1006), 부품 교체(620), 질리지 않는 형태(위시본)
- E6 오래 앉아도 덥지 않다: 그물망(에어론)
- E7 조각은 최소로 (확정 원칙): 토네트 6조각, 판톤 한 덩어리
- E8 필요 없는 것이 없다: 셰이커, 튤립(다리 정리)
- E9 책상 앞으로 당기고 빼기: 바퀴 (역사 목록 밖, 추가 후보)

## 분류 (Claude 초안, 사용자 판단 전)
- 무조건: E1(엉덩이·골반), E2(자세 바꾸기 쉬움), E3, E4, E7, 장식 없음
- 합칠 수 있음: 몸 모양 셸 + 유연함(받침과 움직임을 한 장이) / 그물망(받침 + 바람) / 안장 좌판(열린 각 + 여러 자세) / 받침 하나 = 회전 기둥
- 충돌: ①의자가 움직임 vs 사람이 움직임 ②허리 받침 있음 vs 없음 ③한 덩어리 vs 교체형 부품 ④셸(나무·플라스틱) vs 그물망 ⑤높이 조절 장치 vs 단순함 ⑥팔걸이 있음 vs 없음 ⑦앞으로 기운 작업 자세 vs 뒤로 기대는 자세
- 목적 밖(뺄 후보): 분해 배송, 소파 변신
