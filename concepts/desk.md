# 책상 (1인용) — No more, No less

_상태: 2단계 표현 논의 중 · 2026-10-07_

진행 방식: 기능 정의 → 표현 → 구현 → 종합 (`notes/design-process.md`)

## 1단계. 기능 정의

이데아: **한 사람이 앉아서도 서서도, 생각을 펼칠 수 있는 비어 있는 면.**

| # | 기능 | 출처 | 왜 필요한가 |
|---|---|---|---|
| F1 | 작업하는 면을 받친다 (팔, 종이, 노트북) | 사용자 | 책상의 기본 |
| F2 | 앉은 자세와 선 자세 모두에 맞는 높이 | 사용자 | 사용 방식이 두 가지 |
| F3 | 사람마다 다른 키에 맞춘다 | 사용자 | 같은 자세라도 맞는 높이가 다름 |
| F4 | 위는 비어 있다 — 지금 쓰는 것만 올라온다 | 사용자 | 빈 면이 있어야 생각을 채운다 |
| F5 | 지금 안 쓰는 물건(충전선, 필기구 등)을 위가 아닌 곳에 둔다 | 사용자 | F4를 지키면서도 필요한 물건은 가까이 (No less) |
| F6 | 생각을 펼칠 만큼 넓다 | 사용자 | 넓으면 좋다 |
| F9 | 앉은 자리에서 앞쪽 끝까지 손이 닿고, 옆은 살짝 이동해서 쓴다 | 사용자 | → 깊이 일정, 길게 휜 띠 |

> 기본 조건(이데아에는 넣지 않음, 당연히 지킨다): 흔들리지 않음, 다리·무릎 공간.

## 2단계. 표현 — 최소 단위와 기능 배정

책상의 최소 단위 = **상판 + 다리**. 이 둘 외의 요소는 추가하지 않는다 (No more).
모든 기능은 둘 중 하나가 맡는다.

| 요소 | 맡는 기능 |
|---|---|
| 상판 | F1 받침, F4 빈 면, F6 넓이, F9 곡선(손 닿는 범위), F5 일부 |
| 다리 | F2·F3 높이, F5 일부(케이블 통로), 기본 조건(안정·무릎 공간) |

### 결정
- **A. 상판 = A2 초승달** (앞뒤 모두 곡선). 바깥 곡선 = 손이 닿는 거리 → 버려지는 면적 0%. (`img/desk_shapes_A.png`)

### 상판의 수학 (`scripts/desk_curve_math.py`, `img/desk_curves.png`)
- 초승달 넓이 = (θ/2)(R² − r²) — θ: 감싸는 각도(라디안), R: 바깥 반지름, r: 안쪽 반지름
- 가로 폭 = 2R·sin(θ/2), 앞뒤 깊이 = R − r·cos(θ/2)
- R=70, r=25, 180° → 0.67㎡ ≈ 일반 120×60 책상(0.72㎡)의 93%
- 140×70, 160×80 넓이를 맞추려면 R=83~113cm → 손이 닿는 70cm를 넘는다
- 원이 아닌 곡선(슈퍼타원, 큰 원의 일부)은 70cm 안에 두려면 모서리가 닿지 않거나(13~21%) 넓이가 줄어든다

### 수정 (사용자 의도 재확인): 깊이 일정 + 길게 휜 띠, 옆으로 이동하며 쓴다
- 넓이 = 깊이 × 중심선 길이 (휘어도 같다) → 160×60 책상 = 깊이 60, 중심선 160cm 띠
- 감싸는 각도 θ = L/ρ, 양 끝 가로 폭 = 2ρ·sin(θ/2), 가운데 휨 = ρ(1−cos(θ/2))
- 깊이 한계: 몸~상판 거리(약 12cm) + 깊이 ≤ 70cm → **깊이 ≤ 약 58cm**
- 곡률이 클수록(ρ 작을수록) 가운데 자리에서 닿는 면적이 늘고 이동이 줄어든다 (`img/desk_band.png`)

### 전환: 곡선 대신 모듈 (사각형 R + 삼각형 T) — `img/desk_modules.png`
- 이유: 곡선은 만들기 어렵다. 한 사람이 앉아 쓰는 사각형 단위가 있고, 삼각형으로 꺾으면 곡선에 가까워진다.
- 기하: T = 두 변이 깊이 D와 같고 꼭지각 α인 이등변삼각형 → 두 R 사이를 정확히 채우고 깊이가 일정하게 유지된다.
  α=30°면 12개, 45°면 8개로 한 바퀴. 직선 자르기만으로 만든다.
- 임시 치수: R 80×58, T 30°
- 새 기능 후보 F10: 사람·작업에 맞게 형태를 바꾼다 (사용자 확인 필요)
- 열린 질문: R 폭(60/80?), α(15/30/45°), 모듈 연결 방식, 삼각형 꼭짓점(몸 쪽 뾰족한 끝) 처리,
  다리는 모듈마다? → 모듈마다 높이를 다르게(앉는 칸 + 서는 칸) 할 수도 있음

### 정사각형 모듈 검토 (사용자 제안: 80×80)
- 장점: 어느 방향으로든 붙일 수 있다 (회전 대칭) → 조합이 늘고 갈래(ㅗ, ㅜ, +자)도 가능. 삼각형도 한 종류.
- 문제: 앉은 상태에서 몸~상판 12cm + 80cm = 92cm > 팔 70cm → 뒤쪽 약 22cm(면적의 약 28%)는 앉아서 손이 안 닿음.
- 대안: 60×60 정사각형 (12+60=72, 거의 다 닿음) / 80×80 그대로 두고 뒤쪽 띠를 다른 용도로 / 80×58 직사각형 유지

### 근거: 사용자의 현재 책상
- 160×80 책상을 **80×80 작업 공간 두 개**로 나눠 쓰고 있다 → 모듈 기준 80×80 (실제 사용에서 나온 단위)
- 사용자 확인: 뒤쪽 약 20cm는 거의 안 쓴다 → 실제 쓰는 깊이 ≈ 60cm (Barnes 최대 작업 영역 55~65cm와 일치, `notes/ergonomics-reach.md`)

### 결정: 기본 단위 = 80×60 (사용자 결정)
- 폭 80 = 현재 책상의 한 칸, 깊이 60 = 실제 쓰는 깊이 (최대 작업 영역)
- 곡선일 필요는 없다 → 기본 단위 + 여러 모양의 연결 조각으로 형태를 만든다 (F10 사실상 채택)

### 연결 조각 (`img/desk_connectors.png`, `scripts/desk_connectors.py`)
- 규칙: 모든 연결 변 = 60cm (기본 단위의 깊이)
- 조각 후보: 정사각 60×60(각진 꺾기·갈래), 쐐기 30°/45°(비스듬한 꺾기), 부채꼴 90°(둥근 꺾기)
- 정사각 하나로 직선·ㄱ·ㄷ·ㅗ·십자가 다 나온다
- 열린 질문: 조각을 몇 종류까지 둘 것인가 (No more)

### 최소 단위: 조각 한 종류 (`img/desk_single_unit.png`)
- 80×60 하나만으로 직선·ㄱ·ㄷ·ㅜ·바람개비가 된다: 짧은 변끼리 → 직선, 짧은 변을 긴 변에 → 꺾기·갈래
- 4:3 비율 → 가로 3개 = 세로 4개 = 240cm, 섞어 놓아도 끝이 맞는다
- 바람개비 배치는 가운데 20×20 구멍이 생긴다 → 케이블 통로 후보 (F5)
- 비스듬한 각도가 꼭 필요할 때만 쐐기 1종 추가 검토

### 시중 대형 책상과 비교 (2026-10-07 조사)
- 시중: 1400×800, 1600×800, **1800×800(2인용·넓은 1인용 '황금 사이즈')**, 2000×800~1000. 깊이는 대부분 700~800, 600도 있음
- 2개 붙이기: 짧은 변끼리 160×60 (가로는 1600급과 같고 깊이만 20 얕다) / 긴 변끼리 80×120 (마주 앉는 2인)
- 3개: 240×60, ㄱ자 140+80
- 모니터: 모니터 암으로 해결 (사용자 결정) → 깊이 60 유지
