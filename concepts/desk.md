# 책상 (1인용) — No more, No less

_상태: 2단계 표현 논의 중 · 2026-10-07_

진행 방식: 기능 정의 → 표현 → 구현 → 종합 (`notes/design-process.md`)

## 1단계. 기능 정의

이데아: **한 사람이 앉아서도 서서도, 생각을 펼칠 수 있는 비어 있는 면.**

| # | 기능 | 출처 | 왜 필요한가 |
|---|---|---|---|
| F1 | 작업하는 면을 받친다 (팔, 종이, 노트북) | 사용자 | 책상의 기본 |
| F2 | 앉은 자세와 선 자세 모두에 맞는 높이 | 사용자 | 사용 방식이 두 가지 |
| F3 | 사람마다 다른 키에 맞춘다 | 사용자 | 같은 자세라도 맞는 높이가 다름 |
| F4 | 위는 비어 있다 — 지금 쓰는 것만 올라온다 | 사용자 | 빈 면이 있어야 생각을 채운다 |
| F5 | 지금 안 쓰는 물건(충전선, 필기구 등)을 위가 아닌 곳에 둔다 | 사용자 | F4를 지키면서도 필요한 물건은 가까이 (No less) |
| F6 | 생각을 펼칠 만큼 넓다 | 사용자 | 넓으면 좋다 |
| F9 | 자리를 옮기지 않고 모든 곳에 손이 닿는다 | 사용자 | → 몸을 감싸는 곡선형 |

> 기본 조건(이데아에는 넣지 않음, 당연히 지킨다): 흔들리지 않음, 다리·무릎 공간.

## 2단계. 표현 — 최소 단위와 기능 배정

책상의 최소 단위 = **상판 + 다리**. 이 둘 외의 요소는 추가하지 않는다 (No more).
모든 기능은 둘 중 하나가 맡는다.

| 요소 | 맡는 기능 |
|---|---|
| 상판 | F1 받침, F4 빈 면, F6 넓이, F9 곡선(손 닿는 범위), F5 일부 |
| 다리 | F2·F3 높이, F5 일부(케이블 통로), 기본 조건(안정·무릎 공간) |

### 결정
- **A. 상판 = A2 초승달** (앞뒤 모두 곡선). 바깥 곡선 = 손이 닿는 거리 → 버려지는 면적 0%. (`img/desk_shapes_A.png`)

### 상판의 수학 (`scripts/desk_curve_math.py`, `img/desk_curves.png`)
- 초승달 넓이 = (θ/2)(R² − r²) — θ: 감싸는 각도(라디안), R: 바깥 반지름, r: 안쪽 반지름
- 가로 폭 = 2R·sin(θ/2), 앞뒤 깊이 = R − r·cos(θ/2)
- R=70, r=25, 180° → 0.67㎡ ≈ 일반 120×60 책상(0.72㎡)의 93%
- 140×70, 160×80 넓이를 맞추려면 R=83~113cm → 손이 닿는 70cm를 넘는다
- 원이 아닌 곡선(슈퍼타원, 큰 원의 일부)은 70cm 안에 두려면 모서리가 닿지 않거나(13~21%) 넓이가 줄어든다

### 열린 선택
- **B. 높이 조절**: B1 전동 연속 / B2 가스 스프링(손잡이) / B3 단계식 핀
- **C. 다리 배치**: C1 양 끝 2개 / C2 뒤쪽 중앙 기둥 1개 / C3 곡선을 따라 3개
- **D. 안 쓰는 물건(F5)**: D1 상판 속 덮개 홈 / D2 상판 아래 얇은 트레이 / D3 다리 속 케이블 통로 (다른 것과 조합 가능)
- **E. 충전 중인 휴대폰은 '지금 쓰는 것'인가?** (위에 올라와도 되는가)
