# 회사 사무실 — No more, No less

_상태: 0단계 방향 정하기 · 2026-10-13_

진행 방식: 철학 → 기능 → 최소 단위 → 표현 → 구현 → 종합 (`notes/design-process.md`)

## 큰 방향 (사용자)
- 궁극적인 목표는 **회사**와 **사는 집**의 공간을 디자인하는 것.
- 방법: 공간 한 곳을 정해 끝까지 설계하고, 그 공간에 필요한 물건(부품)을 하나씩 직접 만든다.
  공간이 요구하지 않는 물건은 만들지 않는다.
- **회사부터** 시작한다. 건물은 손대지 않고 사무실 안을 설계한다.
- 구글·메타·애플처럼 회사의 철학이 공간에 드러나는 사무실을 만들고 싶다.
  우리 사무실의 철학은 No more, No less.
- 책상 001은 이 사무실의 첫 부품 후보다.

## 확인할 것
- 실제 회사인지(사용자의 회사), 어떤 일을 하는지, 몇 명인지
- 공간 크기, 평면도, 창·문 위치, 바꿀 수 있는 범위(임대 여부)
- 지금 사무실에서 불편한 점, 좋은 점 (경험)

## 조명 메모 (2026-10-13)
- 사무실은 무광(난반사) 표면이 기본: 눈부심·화면 비침을 줄인다. 권장 반사율(EN 12464-1, 기억값·원문 확인 필요)
  천장 70~90%, 벽 50~80%, 바닥 20~40%, 책상 면 20~60%. 책상 001 마감재(리놀륨 vs HPL) 판단 근거.
- 채광 튜브: 옮길 때는 정반사(거울 튜브), 눈앞에서는 난반사(확산판).
- 스탠드 비교 렌더 `renders/005_lamp_compare.png` (같은 빛의 양, 방의 다른 불은 끔)
  | 방식 | 보이는 느낌 |
  |---|---|
  | ① 갓 스탠드 | 가운데만 동그랗게 밝고, 끝은 어둡다 |
  | ② 긴 막대 + 확산판 | 책상 끝에서 끝까지 고르다 — 펼친 면 전체 |
  | ③ 위아래 겸용 | 책상은 조금 어둡지만 벽까지 밝아 밝기 차이가 가장 작다 |
  | ④ 간접만 | 책상이 어둑하다. 스탠드 하나로는 빛이 부족 |
- 사용자 질문 "그럴 거면 천장 불을 켜면 되지 않나?" → 원칙 10.
  **순서: 천장 조명을 먼저 정하고, 남는 문제가 있을 때만 스탠드를 만든다.**
- 비슷한 시중 제품: BenQ e-Reading(폭 90cm를 밝히는 넓은 머리), LUCTRA Table Linear(머리를 돌려 직접·간접),
  Waldmann 등 사무실용 바닥 스탠드(직접+간접, 독일 사무실에 흔함), 모니터 걸이등.
