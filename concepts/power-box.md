# 멀티탭 상자 — 책상 아래에 자석으로 붙이는 상자

_상태: 형태 논의 중 · 2026-10-07_

## 기능
- 멀티탭을 책상 위가 아닌 아래에 둔다 (책상 F5)
- 멀티탭 꼬리(전원선)가 나가는 곳
- 꽂힌 플러그마다 선이 빠져나갈 곳
- 쉽게 붙였다 떼고 옮긴다 (자석, 2kg 이하)
- 충전기 열이 빠진다

## 규격 후보
- 긴 것 / 짧은 것 두 가지
- 구 수: 쓰는 기기 수로 정한다 (사용자 확인 대기)
- 한국 멀티탭 대략: 3구 ≈ 25cm, 4구 ≈ 30cm, 6구 ≈ 40~45cm, 폭 5~6cm, 높이 3.5~4.5cm (제품마다 다름)

## 선이 빠지는 방식 후보
- A. 위가 열린 얕은 쟁반 (ㄷ자 단면): 가장 단순, 열 잘 빠짐, 위에서 보면 선이 보일 수 있음(책상 아래라 상관 적음)
- B. 한쪽 긴 면이 열린 상자: 멀티탭을 세워 콘센트가 열린 면을 향함
- C. 닫힌 상자 + 솔(브러시) 틈: 가장 깔끔, 부품 추가, 열 갇힘

## A안 1차 모델 (2026-10-07) — `renders/002_power_box_front.png`, `_empty.png`, `_back.png`
- 긴 것 46×8×6cm (6구 42cm), 짧은 것 29×8×6cm (3구 25cm)
- 뒷벽 6cm (자석 지름 3cm × 2), 앞 턱 2.5cm, 옆판은 뒤→앞으로 비스듬히, 한쪽 옆판 아래 꼬리 홈
- 알루미늄 판 1.5mm 접기, 분체도장(책상 색)
- 발견: 충전기를 꽂으면 바닥에서 약 7.5cm + 선이 휘어 올라갈 공간 → 상자를 프레임에 그대로 붙이면 충전기가 상판 아래에 닿는다
  → 뒷벽을 위로 늘려(약 10cm) 위쪽 4cm만 프레임에 붙고, 쟁반은 그 아래에 매달리게

## 강철 상자 + 고무 자석 (사용자 제안, 2026-10-07)
- 강철끼리는 붙지 않는다 → 둘 중 하나는 자석이어야 함
- '고무를 씌운다' = 고무 자석 시트(냉장고 자석 재질)를 뒷벽 접촉 띠(높이 4cm)에 붙이면 상자 전체가 그대로 붙음
- 힘(대략, 시트 20~40g/cm², 미끄럼 0.5, 안전율 2): 긴 것 0.9~1.8kg, 짧은 것 0.6~1.2kg → 멀티탭+충전기 1~1.5kg이면 긴 것은 경계
- 대안: 강철 상자 안쪽에 작은 원형 자석을 숨김(강철 상자가 자력을 모아 줘 더 셈) + 바깥에 얇은 고무 패드
- 강철 상자는 프레임과 같은 재료·같은 도장 → 책상 하부가 한 재료로 통일, 알루미늄보다 싸고 접기 쉬움

## v2 (사용자 정리: 상자는 강철일 필요 없음) — `renders/002_power_box_v2_*.png`
- 알루미늄 쟁반 + 뒷면 위쪽 4cm 띠에 작은 자석을 넣고 고무 시트로 덮음 → 프레임(강철)에 붙음
- 알루미늄이라 가벼워 자석 부담이 줄어든다 (강철판보다 약 1/3 무게)
- 뒷벽 12cm = 붙는 띠 4 + 틈 2 + 쟁반 6 → 쟁반이 프레임 아래로 매달려 충전기 위로 선이 휘어 나갈 공간이 생김

## v3 논의: 전체 등판 대신 작은 고리 몇 개 (사용자 제안)
- 맞다: 등판의 역할은 '쟁반을 프레임 아래로 띄워 매다는 것'뿐 → 폭 2~3cm 탭 2개면 충분
- 탭 + 자석: 고무 시트는 넓어야 버티지만, 네오디뮴 원형 자석(지름 2~2.5cm)은 탭 하나에 하나로 충분 (2개 합쳐 약 1.2kg 이상, 대략)
- 탭 + 고리(프레임 구멍에 끼움): 자석·고무 없음, 가장 단단, 위치는 구멍 간격(5cm)마다 — 이미 있는 구멍을 모든 수납이 같이 씀
  - 판 탭이 끼워지려면 구멍을 가로(20×5mm)로 돌리는 게 자연스럽다
