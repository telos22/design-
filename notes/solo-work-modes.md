# 혼자 하는 일 4가지 — 거꾸로 변환으로 이상 정의, 방해 요인, 기존 해결 (2026-10-08)

맡는 곳: 의자 / 책상 / 공간 / 행동(사람이 일하는 방식)

## 1. 창작 (깊은 집중)
- 이상(추상): 하던 생각이 끊기지 않고 이어진다
- 반대(현실): 일이 끊겨 돌아오는 데 시간이 든다 — Mark: 중단된 일의 82%를 같은 날 다시 잡고, 평균 약 23분, 그 사이 다른 일 약 2개 (36명 3일 관찰)
- 방해 요인
  - 주변 시야로 사람·움직임이 들어온다 → Brody(Steelcase 2015): 3면 칸막이로 주변 시야 차단. Steelcase+위스콘신대 약 70명: 시각적 차단이 집중을 유의하게 높임 (회사 연구) [공간·가구]
  - 개방형 사무실 → Bernstein & Turban 2018: 대면 대화 약 70% 감소, 메신저·메일 증가 [공간]
  - 휴대폰이 눈앞에 있다 → Ward 2017(약 800명): 책상 위 폰 < 가방 < 다른 방, 꺼져 있어도 뒤집어 놔도 같음 [책상·행동]
  - 필요한 물건을 가지러 일어난다 / 몸이 불편하다 → 의자 D1~D14 [의자·책상]
  - 책상 위가 어지럽다 → 책상 001 F4 '위는 비어 있다' (Claude 연결, 근거 미조사) [책상]

## 2. 처리·응답
- 이상(추상): 답할 일을 짧게 처리하고 바로 창작으로 돌아간다
- 반대(현실): 알림·확인 때마다 창작이 끊기고 스트레스가 쌓인다
- 방해 요인
  - 수시로 확인한다 → Kushlev & Dunn 2015(124명): 하루 3번만 확인 + 알림 끔 → 스트레스 유의하게 감소 (효과는 작은 편) [행동]
  - 처리용 기기(폰)가 창작 자리 안에 있다 → Ward 2017 [책상]
  - 가구로 푼 기존 사례는 조사에서 찾지 못함 → 폰을 둘 자리(시야 밖)는 Claude 제안

## 3. 관조 (멈춰서 생각·쉼)
- 이상(추상): 잠깐 멈춰 돌아보고, 주의가 회복된다
- 반대(현실): 쉬어도 피로가 안 풀린다 (쉬면서도 화면·벽을 본다)
- 방해 요인
  - 볼 곳이 없다 → Lee 2015(대학생 150명): 40초 초록 지붕 보기 → 주의 과제 오류 감소. Kaplan 주의 회복 이론: 자연은 힘들이지 않는 주의를 끌어 피로를 회복. 창밖 자연이 보이는 직원이 직무 만족 높음(상관) [공간]
  - 기댈 곳이 없다 → 의자의 기대기, 라운지 의자 [의자]
  - 쉬려면 자리를 옮겨야 한다 → 그 자체가 끊김 (Claude 추정) [의자·공간]

## 4. 공부 (읽기·정리·외우기)
- 이상(추상): 읽고 쓰는 동안 몸이 버티고, 배운 것이 남는다
- 반대(현실): 책·노트를 내려다보느라 목과 몸통이 숙여져 지친다
- 방해 요인
  - 평평한 책상 위 책을 내려다본다 → 2016(Work): 15° 경사면이 목 굽힘 감소 / 2012 학생: 기울인 상판이 몸통·목 굽힘 감소 / Bridger(강의자료 인용): 경사면 → 몸통 움직임·목 굽힘·피로 감소 [책상]
  - 단, 기울인 판은 어깨 근육을 더 씀 (프랑스 연구) [책상]
  - 읽기(기대기)와 필기(앞으로 기울기)를 계속 오간다 → 의자 D3 [의자]
  - 기존 해결: 경사 책상, 필기 경사판, 책 받침대

## 사용자 정리 (2026-10-08)
- 창작: 폰·물건 → 책상 001 아래 상자에 / 위가 어지러움 → 이미 '위는 비어 있다' / 시야·트인 사무실 → 공간 단계로 / 알림 → 각자(행동), 제외
- 처리·응답: 제품으로 해결할 것 없음
- 관조: 의자에서 쉴 수 있어야 한다(기대기) — 의자 몫
- 공부: 책상 전체를 기울이지 않고 위에 올리는 독서대로 (책상을 기울이면 손이 기울어진 판 위에서 일해 어깨를 더 씀)
- 지적: 방해 요인만으로는 제품을 디자인할 수 없다 → 각도·높이·넓이 같은 구체 사양이 필요
